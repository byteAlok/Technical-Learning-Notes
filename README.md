## 🧭 Exploring Technologies & Choosing a Direction

During my learning journey, I explored different programming languages, frameworks, databases, and development approaches to understand their capabilities and potential use cases.

This is one reason the repository includes syllabuses and roadmaps for technologies that I may not currently use in my projects.

Exploring these options helped me understand the differences between technologies and consider which tools might be suitable for different types of applications.

### My Current Technology Direction

My current development direction includes the following technologies, depending on project requirements:

- **ASP.NET Core MVC** — For applications where the MVC architecture is suitable.
- **ASP.NET Core Web API** — A preferred backend approach for many API-driven applications.
- **React.js** — For selected frontend applications.
- **Next.js** — For projects where its framework capabilities are useful.
- **Node.js and Express.js** — For selected backend implementations.
- **SQL and NoSQL databases** — Including Microsoft SQL Server, MongoDB, and MySQL, depending on application requirements.

I do not consider one technology the best choice for every project. The selection of a framework, architecture, and database depends on the application's requirements and the problem being solved.

Other technologies documented in this repository remain useful learning references, even when they are not part of my current development direction.
